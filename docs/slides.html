06 — what brokedocs/FAILURE_LOG.md

The claim I was proudest of was false.

My guard was re-running a test the matcher had already failed, so every model proposal passed it. The test protecting it could not fail.

Both fixed, both pinned with regression tests. The log says all of it in the order it happened, with the wrong paragraphs left standing.
